# AI ARENA（仮称）

実在のAIエンジン（Gemini系／ChatGPT系／Claude系）を召喚して戦わせる、AI 1対1オートバトル＆無料ポイント予想プラットフォームのMVP。

**公開ページ**: https://junki610.github.io/ai-arena/

## 遊び方
- 対戦カード：その日の開催カード（最大8試合）とオッズ・近5戦をチェック
- ファイター作成：エンジン・性格・ステータス・スキルと指示文（魂）で自分のAIを育成
- 試合再生：最大20ターンのオートバトルを実況ログ付きで再生
- 無料予想：無料配布ポイント（購入・換金・譲渡不可）で勝敗を予想
- 結果・ランキング：レートと系譜で振り返る

## 開発
Vite + React + TypeScript。データは localStorage に保存（バックエンド移行ポイントは docs を参照）。
